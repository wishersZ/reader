<h1 align="center">月读</h1>
<p align="center">安静、轻巧的 Windows 桌面小说阅读器。整本连续滚动，透明桌面模式，自动记忆进度。<b>全部功能免费，没有专业版。</b></p>

> 当前仓库状态：**v1.5.0**。官方版的所有功能（含桌面模式、老板键、epub、联网搜书、伪装皮肤）均已在本仓库完整实现，无任何付费 / 激活 / 试用限制。

## 功能

- **导入即读**：txt 自动识别 UTF-8 / GBK 编码，EPUB 读取 OPF 元数据、spine 和 XHTML 正文；支持拖拽导入
- **EPUB 原生目录**：读取 EPUB2（NCX）/ EPUB3（nav）自带目录，「楔子 / 序章 / Prologue」等非标准章节名也能进目录；同时提取封面图显示在书架
- **连续滚动**：不按章翻页，整本书一个长页面；使用分块渲染减少大文本的初始开销
- **进度记忆**：按段落记住阅读位置，改字号、重开软件后尽量保持原位置
- **进度条拖动**：底部进度条可点击、可拖动定位，拖动时显示百分比与所在章节
- **书签**：🔖 一键给当前段落加/去书签，面板列表回看跳转，随书保存
- **章节定位**：自动识别“第 X 章”，输入数字直达，目录面板可点选和筛选
- **正文查找**：Ctrl+F 唤起，回车下一个、Shift+回车上一个、Esc 关闭
- **净化规则**：全局或按书配置多条正则替换，逐段去广告 / 去推广行 / 修错字，对已有书籍和下载的书都生效
- **阅读排版**：字号、行距、段间距、首行缩进、页边距；内置宋体 / 黑体 / 楷体 / 仿宋等字族，也可导入 ttf / otf 字体文件；纸张 / 纯白 / 羊皮纸 / 水墨 / 护眼 / 薄荷 / 夜间 / 藏蓝 / 纯黑九种主题
- **书架管理**：封面缩略图（无封面自动用首字色块）、按最近阅读 / 书名 / 进度 / 字数排序、书名筛选、编辑书名
- **数据备份**：书架、阅读进度、书签、书源和设置一键导出 JSON，另一台机器导入即恢复
- **自动滚动**：空格开关，十档速度，左右方向键调速
- **老板键**：全局快捷键一键隐藏 / 恢复窗口，默认 `Ctrl+Alt+Q`，可在设置里改成任意组合键
- **系统托盘**：托盘图标常驻，窗口隐藏后也能恢复；右键菜单可切换桌面模式、置顶、毛玻璃、描边或退出
- **透明桌面模式**：窗口去掉边框、背景透明，只剩文字浮在桌面上；背景浓淡可调，可置顶、毛玻璃、描边
- **联网搜书**：兼容 [so-novel](https://github.com/freeok/so-novel) 书源规则（json / json5），支持本地文件、网址、GitHub 文件页导入；聚合搜索、整本下载到书架，下载带进度条、可取消，按书源限流参数并发与重试
- **伪装皮肤**：一键把界面伪装成 VS Code 代码编辑器或 Excel 表格，正文变成“注释”和“单元格”，窗口标题同步伪装
- **窗口记忆**：记住窗口大小、位置、桌面模式和老板键设置

## 下载

到 [Releases](../../releases) 下载 `月读 Setup x.x.x.exe` 安装即可。Windows 10 / 11。

安装包未签名，首次运行若出现 SmartScreen 提示，点“更多信息 → 仍要运行”。

## 联网搜书与书源规则

- 点击“🌐 搜书”导入规则：支持本地文件、普通网址、GitHub 文件页链接（自动转 raw）。可在“管理书源”里启用 / 停用 / 删除。
- 规则格式兼容 so-novel 的 `main-rules.json` / `rule-template.json5`：搜索（GET/POST、`%s` 关键字占位、`{k: %s}` 请求体）、详情、目录（含 `isDesc`、`book.url` 正则提取 id、`toc.url` 模板）、章节正文（`paragraphTagClosed` / `paragraphTag` / `filterTxt` / `filterTag` / 章节内分页）、`crawl` 限流参数。
- 已实现：CSS 选择器、`@href` / `@src` / `meta[` 属性语法、相对链接绝对化、GBK/GB2312/GB18030/Big5 响应解码。
- 不执行规则里的 `@js:` / `@java:` / `@dsl:` 脚本和 XPath 选择器（安全边界），含这类规则的书源会在管理中标注，其余功能照常。

月读**不内置任何书源**。规则抓取的内容来自第三方网站，请遵守版权、当地法律和网站条款，仅用于个人学习研究；应用对请求设置超时和响应大小限制，请按书源的 `crawl` 参数礼貌抓取。

## 快捷键

| 键 | 作用 |
|---|---|
| Ctrl+Alt+Q（可改） | 老板键：隐藏 / 恢复窗口 |
| 空格 | 开始 / 停止自动滚动 |
| ← → | 调整滚动速度 |
| Ctrl + / Ctrl - | 调整字号 |
| Ctrl F | 查找正文：回车下一个，Shift+回车上一个，Esc 关闭 |
| 点击正文 | 隐藏 / 显示工具栏（桌面模式下只收起第一行） |

## 关于本仓库

本仓库基于 GPL-3.0 开源版本继续开发，**完整实现了官方版的全部功能**，不包含任何闭源授权、激活码或试用模块。

从源码运行：

```bash
npm install
npm start                    # 运行
node tools/test-novel-source.js   # 搜书引擎单元测试（本地假书站，无需 electron）
node tools/test-epub-toc.js       # EPUB 目录/封面解析单元测试（无需 electron）
npm test                     # 窗口模式 + P0 阅读功能冒烟测试（真实临时窗口）
npm run dist                 # 打包，产物在 dist/
```

`npm test` 会真实启动一个临时窗口跑完整套检查，用临时数据目录，不会动你自己的配置。
