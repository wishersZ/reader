⚙ 设置

老板键

全局快捷键：在任何程序里都能一键隐藏 / 恢复月读窗口，默认 Ctrl+Alt+Q。鼠标点进输入框后直接按下新组合键即可（至少带一个 Ctrl / Alt / Shift）。

伪装皮肤

皮肤

一键把界面伪装成 VS Code 或 Excel：正文变成绿色“注释”或表格“单元格”，窗口标题同步伪装。所有阅读功能照常可用，工具栏 ⚙ 里可随时切回。

系统托盘

月读常驻托盘：左键点托盘图标显示 / 隐藏窗口，右键菜单可切换桌面模式、置顶、毛玻璃、描边，或退出。

透明桌面模式

开启后窗口去掉边框、背景透明，只留文字浮在桌面上；工具栏第二行能调背景浓淡、置顶、毛玻璃和描边。窗口大小和位置会记住。毛玻璃需要 Windows 11 22H2 及以上。

净化规则

对书籍正文逐段做正则替换：去广告、去推广行、修常见错字。可设全局规则，也可给单本书单独加规则；对书架里已有的书和今后下载的书都生效。

数据备份

把书架、阅读进度、书签、书源和设置导出成一个 JSON 文件；在另一台机器上导入即可原样恢复（同 ID 的书籍会被覆盖，其余保留）。

🧹 净化规则

逐段执行正则替换（自动带全局标志 g），「替换为」留空 = 删除匹配内容。示例：把 .*最新网址.* 替换为空可删掉常见广告行；把 的地得错字 替换为 正确的字。勾掉即停用，不删除。
