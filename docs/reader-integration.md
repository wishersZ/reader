# 月读 · 拆分导出功能整合说明

把「长篇小说拆分工具」(`tools/novel_split/novel_split.py`) 的拆分能力整合进月读
(`projects/reader/`)，让阅读器可以在选中一本书后，一键导出成**按卷或按份数切好的若干 TXT**，
供 AI 逐份分析。

## 为什么这样整合

月读原本已经具备：书架、txt 导入（UTF-16 / UTF-8 / GBK 自动识别）、连续滚动阅读、进度记忆、
章节定位。它缺的正好是「把长篇切小以喂给大模型」这一环——两者天然互补。

三种整合方式的取舍：

| 方式 | 结论 |
|---|---|
| 打包 Python 脚本、运行时调用 | ✗ 安装包用户机器上没有 Python |
| 把逻辑重写成 JS 模块 | ✓ **采用**：无额外依赖，随 `src/**` 一起打包 |
| 让用户去用外部命令行工具 | ✗ 与阅读器体验割裂 |

## 架构

```
渲染进程 (src/index.html)          主进程 (src/main.js)             模块
  🧩 拆分 按钮  ──IPC──▶  split:preview   分析结构，不写盘  ──▶ src/splitter.js
  导出弹窗      ──IPC──▶  split:export    选目录 + 写文件    ──▶   （纯逻辑，无 Electron 依赖）
  结果展示      ──IPC──▶  open-path       打开导出目录
```

要点：

- 小说正文存在渲染进程的 **IndexedDB**（`novelReader` / `books`），而渲染进程在
  `contextIsolation: true` 下不能写盘，所以正文通过 IPC 交给主进程处理。
- `src/splitter.js` 是 **CommonJS 模块，只被主进程 require**；渲染层不加载它，
  避免大文本进入 UI 线程。
- 实测 7 本 100 万~1000 万字的小说，单本「分析 + 切分」耗时 **0.34~2.3 秒**，
  直接在主进程跑即可，不需要 worker。渲染进程是独立进程，期间仍能正常重绘。

## 功能行为

- **自动**：有卷标记（≥2 个）按卷切，否则按份数均分。每卷一个文件
  `《书名》_第一卷 化龙.txt`；无卷则 `《书名》_第一部分.txt`…
- **按卷 / 按数量 / 按字数上限 / 整本另存 UTF-8** 四种模式可手动指定。
  不填份数时按每份约 10 万字自动决定。
- 顺带处理：清理广告水印行、统一段首缩进（2 个全角空格）与换行、识别
  `第X章` / `第X卷` / `序章` / `番外`、**章号重置**（每卷从 001 重新开始）自动分段排序、
  剔除正文里被误认成章节的列表。
- 导出目录除正文外还有 `00_目录索引.md`、`01_章节清单.tsv`、`manifest.json`、
  `_已删除行.txt`（可复核误删）。
- **零丢失校验**：写盘后校验「各份净字数之和 == 全书净字数」，并逐文件回读比对。

## 移植时发现并修复的问题

1. **字数口径不一致（真实 bug）**
   JS 的 `String.length` 数的是 UTF-16 **码元**，Python 的 `len()` 数的是 **码点**。
   《反派少爷只想过佛系生活》含 61 个非 BMP 字符（emoji 🀄 与生僻字），
   导致 JS 版净字数比 Python 基准多 61。
   → `netChars()` 改为按码点计数（跳过代理对）。这也更符合「1 个汉字 = 1 个字」的直觉。
2. **JS 语法错误**
   `○`（U+25CB）属于 Unicode Symbol 类别，不能作未加引号的对象键，
   `{ 零:0, 〇:0, ○:0 }` 直接 SyntaxError。→ 所有 CJK 键加引号。

## 已知限制

- **项目里存在两套章节解析器**：渲染层原有的 `parseChapterTitle()` 未改动
  （避免影响目录与阅读进度），导出走 `splitter.js` 里更严格的一套。
  两套逻辑有意分离，代价是有一处重复。
- 单本耗时最长约 2.3 秒，期间主进程被占用（窗口不卡，但主进程自身的 IPC 会排队）。
  若未来遇到更大的书，可把 `splitter.js` 移入 `worker_threads`。
- 纯浏览器环境下无法使用（需要主进程写盘），按钮会提示需在桌面客户端中使用。
- 按卷切分时各卷大小天然不均（实测 21 万~87 万字）；某卷仍超上下文时，可对该卷再导一次
  「按数量」。
