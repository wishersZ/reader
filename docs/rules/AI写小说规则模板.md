# 让 AI 写出好小说：可粘贴的规则模板

> 说明：本模板把「给 AI 写小说的规则」分成 0–8 层。第 0 层（元规则）比后面所有条目都重要；
> 第 2 层是反 AI 味的语言黑名单，收益最快。全部规则都只是兜底，**与作者提供的风格样本冲突时以样本为准**。
> 规则来源与证据等级见文末。

---

## 0. 元规则（先立这四条，再谈别的）

1. **样本优先。** 开写正文前，必须在上下文里放 2–3 段目标风格的原文（目标作者/自己的旧章节）。
   模型靠上下文里的文字定语感，这一步比所有规则加起来都有效。日常写日常的样本，高潮写高潮的样本，不要混用。
2. **写的时候放开写，写完再审。** 不要一边写一边顶着一长串禁令——那会让文字拧巴、缩手缩脚。
   禁令属于审稿阶段（第 7 层）。
3. **AI 不做核心决定。** 主线走向、人物命运、结局、要不要写某个禁忌题材，由作者拍板；AI 只提建议和补细节。
   同时让作者先明确「最不想写成什么样」，这比「想写什么」更能防套路。
4. **给每条"必须打破"的规则配配额。** 规则一旦被执行成习惯，本身就成了新模板
   （例："禁区是给打破用的"→ 如果每卷都打破一次，禁区就不存在了）。打破全书个位数次，且打破后必须有"缝回去"的过程。

---

## 1. 上下文规则：每章开写前必须喂进去的东西

只给「写第 3 章」是最典型的失败输入。最小输入包：

```markdown
## 本章任务
- 章节 / 字数范围 / 视角：
- 场景（地点、时间、在场人物）：
- 开场承接（上一章留下的未完成动作/压力/情绪）：
- 主角目标 + 压力：
- 对手目标 + 压力：
- 必须兑现的（伏笔回收、规则、证据、物件）：
- 必须铺垫的（本章不能回收的钩子）：
- 禁止事项（不能提前泄露/解决的内容、禁用套路）：
- 章末钩子方向：
- 逻辑承接 / 新信息来源（谁知道、怎么知道、为什么现在说）：
- 角色已知 / 未知：
- 关键动作顺序（可拍摄的动作链）：
```

配套三条：
- **角色只喂切面。** 三人以上场景，先定摄像机（这场的视角跟着谁）、主关系轴（谁的张力）、情绪节拍（谁先动、谁沉默）。
- **世界观分层喂。** 总档（规则/势力/地理，少变）+ 当前弧喂包 + 本章喂包。没喂的设定 AI 会自己编，编的跟你想的必然不一样。
- **每个新术语第一次出现就锚定**：是什么、怎么运作、影响谁的什么选择。

## 2. 语言层硬规则（反 AI 味黑名单，收益最快）

### 2.1 词：直接清洗
| 类别 | 样本 | 处理 |
|---|---|---|
| AI 高频词 | delve / tapestry / landscape / pivotal / underscore / testament / intricate / robust / multifaceted / resonate（中译：交织、画卷、图景、至关重要、见证、错综复杂、共鸣） | 删换 |
| 魔法副词 | 静静地、深深地、根本上、微妙地、某种程度上 | 删九成；程度靠具体画面给 |
| 按钮式氛围词 | 回声、幽灵、低语、影子、脉搏、嗡鸣、闪烁、余烬、碎片、深渊 | 同一场景出现 3 个以上=在装饰，不是在写 |
| 极端词 | 非常/极其/无比/十分/极大 | 删九成 |
| 装腔系动词 | "serves as / stands as / 标志着 / 象征着" | 直接用"是" |
| 宏大抽象名词 | 织锦、图景、范式、生态、框架、熔炉、枢纽 | 换成具体词 |

### 2.2 句：AI 最认得出的十个句式（默认全禁，全书最多留 1 次）
1. **否定平行**："不是 X，而是 Y" / "问题不是 X。问题是 Y。" / "并非因为 X，而是因为 Y" —— 最典型的 AI 指纹。
2. **戏剧倒计时**："不是 A。不是 B。只是 C。"
3. **自问自答**："结果呢？毁灭性的。" / "X 是什么？是 Y。"
4. **三连排比**：形容词、动作、后果一律凑三个（要刻意用二、四、一的长度）。
5. **首语重复**：连续三句以上同一开头。
6. **尾巴式升华**：句子后挂"-ing/从而/彰显了/折射出/体现着"。
7. **假区间**："从 X 到 Y"，而 X、Y 之间并无谱系。
8. **填充转折**："值得一提的是 / 然而 / 与此同时 / 不仅如此 / 重要的是"。
9. **破折号滥用**：短篇 2–3 处是人类正常频率，章章十几处就是机器。
10. **独立成段的短促金句**："她走了。" 单独一段、"就这样。" 单独一段——制造出来的强调，不是节奏。

### 2.3 节奏：一条最容易被忽略的规则
- **允许平庸句存在。** AI 小说最深的病是"节奏压缩"：每句都憋着当金句，结果全篇等重，读者反而疲劳。
  "他从门口走到椅子边坐下"这种功能性句子是承重墙，它的平庸让精彩句变精彩。
- **句长必须不均。** 短长交错，偶尔来一个 50 字长句；段落也打破对称（不要每段都三行、字数雷同）。
- **禁止"短句瀑布"**：连续一段全是"她想明白了。她不能再等。她必须反击。她推开门。"——
  要合并成「动作→观察→反应→新决定」的自然链，短句只用在落点上。
- **标点**：并列用顿号，不用句号当顿号；中文省略号用"……"（不是 `...` 或 `。。。`）；破折号极少用；
  简体网文对话用弯双引号 `""`，不用 `「」『』`；正文不用 `【】`（系统流弹窗除外）；不撒 ✦✨◆★ 装饰符。

### 2.4 结构层
- **意象配额**：抽象+具体的"眼球踢"（"瘀青般的沉默""伤疤般的时间戳"）一个故事 1–2 个就够，20 个就是壁纸；同一概念绝不叠多个比喻。
- **人设化比喻**：用任何修辞前先问"它在**这一场**里干了什么活"；答案是"听起来文学"就删。
- **不表演深刻**：不要写"她意识到悲伤不是一个终点，而是一片风景"，要写具体的物和事。
- **一个意思只说一遍**：禁止同义反复（"他非常生气，他怒了"）。
- **不预告结尾**："到最后……""她终于明白……"一律删；结尾要事后必然、事前不提醒。
- **不递归总结**：场景已经演出来的意义不要再解释一遍；不要最后一段复述刚才发生了什么。
- **语域统一**：先给全文定调（朴实/华丽/古风/现代口语），朴实老成的叙述者就不要突然引古诗、蹦学术名词、用不符合身份的梗。
- **拒绝趋同美学**：郁闷、压缩、忧郁、赛博感、满是幽灵与闪烁灯光的"文学 AI 腔"是模型收敛点，不是好文风。凡是"任何一篇 AI 小说里都可能出现"的句子，换成本故事独有的。

## 3. 叙事规则（功能主义）

- **删句测试**：一句话删掉后不影响动作、信息、人物、关系温度、情绪、气氛、节奏、钩子 → 优先删。
- **每句必须有功能**：推进动作 / 改变信息 / 暴露人物 / 制造阻力 / 加情绪 / 兑现回报 / 转场 / 埋钩。
- **每个场景都要有摩擦**：主角刚需要证据，证据就自动出现 = 过度顺滑，是 AI 的典型病灶。
- **证据要可争夺**：不要让外挂/系统自动给出全部真相；给半截，让对手抢先解释成另一种含义，逼主角去抢。
- **动机不解释，只写动作**：写"她转过身去"，不写"她因为害怕暴露柔软转过身去"。句子里出现"因为/本能/源于"来解释行为动机，删掉那个从句。
- **情绪不喊，要演**：不写"她愤怒极了"，写"她把茶盏放回桌上，声音反而低了：'这句话，你敢写进记录吗？'"
- **功能性动作不要直球**：不写"他打开录音""她截图保存"（一眼看出是剧情机关），写"拇指在手机侧边停了一下，最后把屏幕朝下扣在文件夹旁"。
- **新信息必须有来源**，人物判断必须有依据（已知事实/误判/偏见/利益/恐惧/经验/被误导），不能替作者直接知道答案。
- **动作链必须可拍摄**：位置、物件、视线、声音、先后顺序、阻碍都成立（付款、递卡、等支付、拿 POS 单不要混成一团）。
- **叙述者要有性格**：平稳、客观、中性的旁白 = 没有性格的旁白 = AI 默认输出，必须打破。

## 4. 人物规则

- **性格给调色盘，不给标签**：主色调 + 底色 + 对冲色，最少三个；每个性格必须衍生成具体场景动作
  （"温柔"不算，"她不会直接说担心，但会默默把他杯子里的水换成热的"才算）。
- **行为禁区比正面描述有效**：列 5–12 条"常态下不会做的事"，标注例外条件与频率。
  禁区描述的是常态极限，不是人格铁律。
- **禁区是弓，打破是箭**：一个从不哭的人哭一次，比哭一百次都重。打破要稀有（全书个位数），打破后要有恢复（拼命把裂缝缝回去的过程本身就是最好的角色描写）。
- **情感强度匹配场景强度**：日常用日常反应，生死才允许极端。日常崩溃、生死嘴炮，都是公式化。
- **每个主要角色都有自己的目标**，并在大纲里至少有一个只属于她的选择时刻——不能只作为主角的附属出现在关系轴里。
- **让角色不自洽**：真人自相矛盾，说不想说的话、在葬礼上笑、害怕时挑架。AI 默认人物心理过于整洁：一次只感受一种情绪、对话高效推进剧情。

---

## 5. 对话规则

- **自然度 > 金句感 > 爽感 > 文采**。台词可以锋利，但必须先像"这个人物在这个场景里会说的话"。
- **写台词前先标注**：说话人此刻的目标（要对方答应/退让/误判/暴露/闭嘴/留下/离开）、遮掩（不想暴露什么）、关系杠杆（身份差/旧情/利益/规矩/把柄/场合/亏欠/威胁）、句子形状（命令/客气包刀/反问/半句/玩笑藏真话）。
- **说出口的话和心里想的永远不是同一件事**。角色把真实意图说清楚了，就写错了。
- **每句台词至少承担一个场景动作**，且下一句是被上一句逼出来的，不是轮流发表观点。
- **禁止人物替作者念主题**："也许我们都只是失去之人的回声。"——真人不会这么说话。
- **对话要会跑题**：真实对话会重复、绕回、被打断、说废话、彼此错频；不要让每段对话都收在负载的悬念上。
- **换个人说也成立的台词 = 不够人物化**，重写。
- **一个角色一套腔**：每个主要角色至少写 3–5 句"只有他会说"的话，覆盖平常/生气/敷衍/真怕/装没事五种状态。

## 6. 结构规则

- **预先规划，延迟揭示**：把信息按"读者什么时候该知道"来排，而不是一有用地就立刻抛出。早埋细节，后回收。
- **章末用具体未完成动作收束**，不要用压力预告或总结句。（坏："真正的清算，从这一刻开始。" 好："问愿册翻过一页，停在一个没有署名的红印上。红印还湿。"）
- **每章必须有可感知增量**：动作、关系、信息、资源、情绪、气氛、风险，至少推进一项。
- **扩写必须有新增实质**：不能把一句大纲铺成多段空话，必须新增行动、选择、代价或信息。
- **结构不要方块化**：不要"对话块—说明块—叙述块"边界分明地轮播；让人物想法插进句子中间、描写打断对话、动作与反思重叠。
- **不写标题、不用项目符号/编号列表/加粗**——小说里出现这些格式，等于自报 AI。

## 7. 交付与自检规则

- **先放开写，写完再审。** 审稿分两步：先扫表层套句风险，再人工过清单。
- **禁止自夸与台账复述**：不要"本章亮点如下"、不要把剧情再总结一遍当交付物。
- **AI 含量分级（判断必须给文本现象，不许凭感觉）**：
  - `低`：有自然取舍、瑕疵、个性、场景细节；
  - `中`：局部有 AI 润色或模板句，但核心场景和人物目标清楚；
  - `高`：大量均质、空泛、解释性强，人物与冲突被削平；
  - `极高`：整体像提示词扩写，缺少稳定作者判断与可追读场景。
- **含量为"高/极高"时，禁止只做词句替换**：必须回到人物选择、因果压力、对话反应、动作链、现场细节。
- **作者味保护优先**：先列"必须保留的作者味"（口语感、人物毛边、生活细节、土梗、旁白距离），
  不要因为章末不够"标准钩子"就牺牲已经成立的人物关系和场景气氛。
- **最小修订口径**：只修逻辑硬伤、信息缺口、严重水段、视角混乱、合规风险和影响追读的断点；其余有辨识度的毛边先保留。

## 8. 长篇管理规则（防"写到一百章崩了"）

- **每 3 章一批次复盘**，维护状态表：角色状态、伏笔清单、情感债、时间线。
- **跨窗口接力不要直接贴正文**：给结构化摘要 + 限制条件（现在到哪了、角色什么状态、这一段最重要的约束是什么）。
- **不依赖当前提示词记设定**：长线失控（前后矛盾、目标遗忘、伏笔消失、上一章确认的事实被新提示词推翻）是平台判定低质 AI 文的硬红线。

---

## 9. 一条最容易被违反、但最有效的补充规则

**先问"这段像不像一个人在压力现场做出的反应"，再问"句子是否漂亮"。**

AI 的六大通病，本质上都是"过度"：过度对称（三人依次发言、人人立场完整）、过度总结、过度顺滑、
过度正确（每个角色都精准理解作者想表达什么）、过度干净（没有迟疑、误会、抢话、卡顿）、
过度通顺（每段都像被同一个润色器抹平）。规则的作用就是把模型从这几个收敛点推开。
